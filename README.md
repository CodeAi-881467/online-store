# Online Store

A simple online store built with HTML, CSS, and Vanilla JavaScript.

## About the Project

This project is a frontend e-commerce storefront. Users can browse products, view product details, manage their shopping cart, and complete a checkout flow.

## Features

- Display product listings
- Fetch products from the DummyJSON API
- View product details
- Add products to the shopping cart
- Increase or decrease product quantities
- Remove products from the cart
- Save cart data using localStorage
- Checkout form
- Order success page

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- DummyJSON API
- Browser localStorage
- GitHub Pages

## How to Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

## Project Structure

All project files are located in the root directory of the repository.

Main files include:

- `index.html` — Store homepage
- `style.css` — Styles
- `products.js` — Product data and management
- `api.js` — API communication
- `app.js` — Main storefront logic
- `cart.js` — Shopping cart logic
- `product.html` — Product details page
- `checkout.html` — Checkout page
- `order-success.html` — Order confirmation page
